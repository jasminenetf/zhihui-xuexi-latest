# 资源生成依据示例

## 示例 1：函数极限

- 学生问题：我不理解函数极限，讲清定义、常见误区，并给一个例题。
- 检索依据：函数与极限章节；函数极限、左右极限、去心邻域、0/0 型。
- 生成资源：学习讲义、思维导图、练习题、PPT 课件、学习路径、视频脚本、动画预览。
- 讲解要点：极限看趋近过程，函数在该点是否有定义不一定影响极限；左右极限相等才有双侧极限。
- 错因提醒：把 0/0 当答案；只代入不化简；忽略左右极限。
- 推荐路径：先看动画预览，再读讲义定义拆解，最后做 3 道概念辨析题。
- Verifier 检查点：定义、符号翻译、例题和常见误区均能回到课程知识点。

## 示例 2：导数定义

- 学生问题：导数为什么是切线斜率？
- 检索依据：导数与微分章节；导数定义、导数几何意义、平均变化率、瞬时变化率。
- 生成资源：动画预览、学习讲义、练习题、PPT 课件。
- 讲解要点：割线斜率表示平均变化率，当 h→0 时逼近切线斜率，即瞬时变化率。
- 错因提醒：把某一条割线斜率直接当导数；漏掉 h→0 的极限过程。
- 推荐路径：先看导数动画，再完成斜率计算和图像判断题。
- Verifier 检查点：是否出现割线、切线、h→0、f'(x) 等关键证据。

## 示例 3：洛必达法则

- 学生问题：洛必达法则什么时候能用？
- 检索依据：微分中值定理与导数应用章节；洛必达法则、未定式、极限存在条件。
- 生成资源：学习讲义、练习题、动画预览、拓展阅读。
- 讲解要点：先判断 0/0 或 ∞/∞ 未定式，再分子分母分别求导，并重新检查极限。
- 错因提醒：见到分式就求导；没有确认未定式；求导后不检查新极限。
- 推荐路径：先做条件判断题，再做两道基础求极限题。
- Verifier 检查点：是否强调适用条件，不把洛必达当万能技巧。

## 示例 4：定积分定义

- 学生问题：定积分的定义为什么要分割、求和、取极限？
- 检索依据：定积分章节；分割、取样、求和、取极限、积分区间。
- 生成资源：讲义、PPT 课件、动画预览、练习题。
- 讲解要点：定积分表示区间上的累积量，分割越细，求和结果越接近稳定值。
- 错因提醒：把定积分写成原函数族；漏看上下限；把面积解释当作唯一含义。
- 推荐路径：先看小矩形累加动画，再做区间累积量判断题。
- Verifier 检查点：资源不把定积分误写成不定积分，不把面积解释当成唯一含义。

## 示例 5：一阶线性微分方程

- 学生问题：一阶线性微分方程该怎么解？
- 检索依据：微分方程章节；微分方程概念、通解与特解、一阶线性微分方程。
- 生成资源：学习讲义、学习路径、练习题、动画预览、视频脚本。
- 讲解要点：先识别方程类型，再使用标准解法得到通解，最后用初值确定特解。
- 错因提醒：把微分方程当代数方程；漏写积分常数；初值代入错误。
- 推荐路径：先复习不定积分，再完成通解/特解辨析题和一步求解题。
- Verifier 检查点：资源必须区分通解和特解，并说明初值条件的作用。
