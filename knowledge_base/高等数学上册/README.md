# 高等数学上册知识库证据层

本目录是智学工坊最终演示前新增的课程知识库证据层，用于让评委直观看到系统不是只靠模板输出，而是围绕样例课程建立了章节、知识点、检索样例和资源 grounding 说明。

## 文件说明

- `course_manifest.json`：课程元信息、章节、资源类型和检索状态。
- `chapter_outline.md`：高等数学上册章节大纲。
- `knowledge_points.json`：结构化知识点清单，当前包含 40+ 个知识点。
- `rag_sample_queries.md`：学生问题到章节、主题、资源的检索样例。
- `resource_grounding_examples.md`：资源生成如何回到课程依据的示例。

## 与系统功能的关系

1. AI 会话识别学习主题后，匹配课程章节和知识点。
2. 资源生成时把课程依据、学习画像和 Verifier 状态一起写入资源 metadata。
3. 学习报告根据问答、练习、错题和资源使用记录形成学习诊断闭环。
4. 动画预览使用轻量 HTML/SVG/CSS 解释高数抽象概念，不生成 mp4。

## 安全说明

本目录不包含真实 `.env`，不包含 APIPassword，不包含完整版权教材公开分发文件。

## 服务对象

该证据层服务于 RAG 检索、资源生成、学习诊断闭环和 Verifier 引用覆盖检查。正式演示时，对外只说明系统使用“高等数学上册课程知识结构与证据层”，不公开完整版权教材原文。
