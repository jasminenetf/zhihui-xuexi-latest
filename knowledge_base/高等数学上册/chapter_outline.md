# 高等数学上册课程章节大纲

本目录用于给评委展示系统内部课程知识库的组织方式。系统以内置《高等数学上册》课程为样例，围绕章节、知识点、检索样例和资源 grounding 证据支持个性化学习资源生成。

## 1. 函数与极限

- 章节目标：建立函数、极限、连续的基础语言，理解“趋近过程”和“局部稳定趋势”。
- 核心知识点：函数定义域、函数性质、数列极限、函数极限、左右极限、无穷小、无穷大、极限运算法则、两个重要极限、函数连续、间断点分类。
- 常见误区：把极限值等同于函数值；只代入不看左右极限；把 0/0 型直接当答案；忽略定义域和去心邻域。
- 推荐资源类型：学习讲义、思维导图、练习题、动画预览、学习路径。
- 前置关系或后续建议：前置需要函数概念；后续支撑导数定义、连续性和积分极限定义。

## 2. 导数与微分

- 章节目标：理解导数是瞬时变化率，微分是线性近似工具。
- 核心知识点：导数定义、导数几何意义、基本求导公式、复合函数求导、隐函数求导、高阶导数、微分定义。
- 常见误区：把平均变化率当瞬时变化率；复合函数漏乘内层导数；dy 与 Δy 完全混同。
- 推荐资源类型：学习讲义、练习题、PPT 课件、动画预览、视频脚本。
- 前置关系或后续建议：前置依赖函数极限；后续进入中值定理、单调性、极值和优化问题。

## 3. 微分中值定理与导数应用

- 章节目标：用导数研究函数整体变化，并掌握典型极限与图形分析工具。
- 核心知识点：罗尔定理、拉格朗日中值定理、柯西中值定理、洛必达法则、单调性判定、极值与最值、凹凸性与拐点。
- 常见误区：不检查连续和可导条件；洛必达法则未确认 0/0 或 ∞/∞ 未定式；极值点和最值点混淆。
- 推荐资源类型：学习讲义、思维导图、练习题、PPT 课件、动画预览。
- 前置关系或后续建议：前置依赖导数与连续；后续支撑函数建模、积分应用和微分方程。

## 4. 不定积分

- 章节目标：理解不定积分是反向求导，结果是一族原函数。
- 核心知识点：原函数、不定积分定义、基本积分公式、第一类换元积分法、分部积分法。
- 常见误区：漏写积分常数 C；把不定积分结果写成定积分数值；换元后没有回代。
- 推荐资源类型：学习讲义、练习题、动画预览、视频脚本、拓展阅读。
- 前置关系或后续建议：前置依赖导数公式；后续支撑微积分基本公式和定积分计算。

## 5. 定积分

- 章节目标：理解定积分是区间累积量，掌握“分割、取样、求和、取极限”的定义流程。
- 核心知识点：定积分定义、定积分几何意义、可积条件、微积分基本公式、定积分换元法、定积分分部积分法。
- 常见误区：把定积分和不定积分混淆；忘记上下限；只把面积当唯一解释；换元后上下限不同步。
- 推荐资源类型：学习讲义、PPT 课件、练习题、动画预览、学习路径。
- 前置关系或后续建议：前置依赖极限和不定积分；后续进入面积、体积、物理累积量等应用。

## 6. 定积分应用

- 章节目标：把定积分解释为面积、体积、做功等累积量，完成从概念到建模的迁移。
- 核心知识点：平面图形面积、旋转体体积、变力做功、弧长与物理应用。
- 常见误区：不会确定积分区间；微元选取不清；把几何对象和被积函数对应关系写错。
- 推荐资源类型：学习讲义、练习题、拓展阅读、PPT 课件。
- 前置关系或后续建议：前置依赖定积分定义和计算方法；后续支撑工程问题中的连续量建模。

## 7. 微分方程

- 章节目标：理解微分方程用导数关系描述变化规律，区分通解、特解和初值问题。
- 核心知识点：微分方程概念、通解与特解、可分离变量微分方程、一阶线性微分方程、初值问题。
- 常见误区：把微分方程当代数方程求根；通解漏常数；初值条件代入位置错误；未分类就套公式。
- 推荐资源类型：学习讲义、学习路径、练习题、动画预览、视频脚本。
- 前置关系或后续建议：前置依赖导数、不定积分和定积分思想；后续可扩展到工程建模与动态系统。
