# 评委可能追问与回答

## 是否真的调用 Spark？

推荐配置为 Base URL `https://spark-api-open.xf-yun.com/x2`、Model `spark-x`、APIPassword 使用用户自己的科大讯飞 APIPassword。没有 API 时系统会明确使用本地演示模式。

## 为什么动画不是 mp4？

当前阶段选择轻量 HTML/SVG/CSS 动画预览，优先保证可运行和可解释，不生成 mp4。

## 如何防幻觉？

系统展示课程依据、引用覆盖检查、支持断言和风险等级，并保留 Verifier。

## 项目创新点是什么？

对话式画像、多智能体资源生成、错题反馈和学习路径闭环。
