# 科大讯飞 AI 能力调研与比赛版策略

**日期:** 2026-06-15  
**项目:** 智学工坊——面向高校工科基础课的多智能体个性化学习资源生成系统  
**样例课程:** 高等数学上册

## 1. 当前统一口径

比赛演示推荐使用科大讯飞 Spark X2：

- Base URL: `https://spark-api-open.xf-yun.com/x2`
- Model: `spark-x`
- API 字段：APIPassword
- APIPassword 使用用户自己的科大讯飞 APIPassword，不写入仓库和提交包

没有 API 时，系统可以使用本地演示模式完成学习闭环。

## 2. 本项目中的讯飞能力定位

Spark X2 是项目的国产大模型主推理引擎。系统围绕“提问诊断 → 课程依据检索 → 多智能体资源生成 → 练习反馈 → 错题复盘 → 学习报告 → 路径更新”构建学习闭环。

资源类型包括：学习讲义、思维导图、练习题、PPT、学习路径、视频脚本、动画预览、拓展阅读。

## 3. 轻量多模态策略

当前版本提供函数极限、导数定义、定积分、不定积分、微分方程、洛必达法则 6 类轻量 HTML/SVG/CSS 动画预览。

说明：

- 动画可在浏览器中预览。
- 动画可下载为 HTML。
- 当前不生成 mp4。
- 不接入重型数字人链路。

## 4. 为什么不做重型数字人视频

完整数字人视频链路需要额外 API 权限、额度、视频生成、播放器和降级逻辑。对当前比赛初赛交付而言，重型视频生成会增加不稳定风险。当前版本优先保证学习闭环可运行、可验证、可复现。

## 5. fallback 策略

当 Spark X2 因网络、APIPassword 或服务状态失败时，系统明确进入备用模型或本地演示模式，不把 fallback 伪装成真实模型输出。

## 6. 答辩建议表述

> 本项目推荐使用科大讯飞 Spark X2，配置为 Base URL `https://spark-api-open.xf-yun.com/x2`、Model `spark-x`，通过用户自己的 APIPassword 鉴权。没有 API 时，系统仍可使用本地演示模式完整展示学习闭环。

> 多模态方面，我们采用轻量化策略，当前提供函数极限、导数定义、定积分、不定积分、微分方程、洛必达法则 6 类 HTML/SVG/CSS 动画预览，不生成 mp4，以保证演示稳定和跨电脑复现。
