# 智学工坊 Windows 便携版使用说明

## 1. 下载与解压

1. 下载 `智学工坊-Windows-便携版.zip`。
2. 解压到一个英文或中文路径均可的目录，例如桌面。
3. 不要只解压单个 `.bat` 文件，必须保留完整文件夹结构。

## 2. 启动方式

双击：

```text
启动智学工坊.bat
```

启动成功后浏览器会打开：

```text
http://127.0.0.1:5173
```

后端健康检查地址：

```text
http://127.0.0.1:8010/health
```

## 3. 首次配置 Spark API

进入前端页面左侧“模型与设置”，选择 Spark，并填写：

```text
Base URL: https://spark-api-open.xf-yun.com/x2
Model: spark-x
APIPassword: 你的科大讯飞 APIPassword
```

点击“测试连接”。成功后顶部状态会显示 Spark 真实生成。

没有 API 时也可以使用本地演示模板完成学习闭环演示。

## 4. 常见错误

### 端口被占用

启动脚本会尝试清理 `8010` 和 `5173` 的旧监听。如果仍失败，请先双击：

```text
停止智学工坊.bat
```

再重新启动。

### Python 未安装

安装 Python 3.10+，并勾选：

```text
Add Python to PATH
```

### Node 未安装

便携版运行不需要 Node。前端由 Python 静态服务器托管。

### Python 依赖缺失

进入 `backend` 目录运行：

```powershell
python -m pip install -r requirements.txt
```

### 后端启动失败

查看：

```text
logs/startup.log
```

以及“智学工坊-后端8010”窗口中的错误。

### Spark 连接失败

检查三项：

1. Base URL 是否为 `https://spark-api-open.xf-yun.com/x2`
2. Model 是否为 `spark-x`
3. APIPassword 是否复制完整，且不要带多余空格

### 页面打不开

手动访问：

```text
http://127.0.0.1:5173
```

如果仍打不开，检查“智学工坊-前端5173”窗口。

## 5. 比赛演示前检查清单

依次运行：

```powershell
python scripts/qa_startup_check.py
python scripts/verify_p0_smoke.py
python scripts/deep_qa_check.py
```

看到以下输出即为通过：

```text
STARTUP QA PASSED
ALL CHECKS PASSED
DEEP QA PASSED
```

## 6. 安全提醒

1. 不要上传 `.env`。
2. 不要公开 APIPassword。
3. 不要把个人 API 密钥写入 README、报告或截图。
4. 发行包只应包含 `.env.example`，不应包含真实 `.env`。
