# 朋友下载运行说明

> 给非开发者的朋友看的：下载项目后如何在自己的电脑上运行。

## 前提条件

- 推荐有一个科大讯飞 Spark API Password；没有也可以使用 Mock fallback 稳定演示
- 可选：DeepSeek API Key（在 [platform.deepseek.com](https://platform.deepseek.com) 注册获取）
- 电脑上已安装 Python 3.10+ 和 Node.js 18+

## 快速开始（7 步）

### 第 1 步：一键启动

Windows 直接双击项目根目录：

```text
启动智学工坊.bat
```

如果需要手动启动后端：

```bash
cd backend
pip install -r requirements.txt
uvicorn app.demo_main:app --host 127.0.0.1 --port 8010
```

后端启动后保持终端窗口不要关闭。

### 第 2 步：打开前端

在浏览器打开：

```text
http://127.0.0.1:5173
```

### 第 3 步：进入设置页

点击左侧导航栏的 **系统设置**。

### 第 4 步：填写 Spark 或 DeepSeek API Key

推荐先填写 **科大讯飞 Spark API Password**。如果暂时没有 Key，可以不填，系统会进入 Mock fallback 演示模式。

### 第 5 步：保存并测试

1. 点击 **保存配置**
2. 点击 **测试连接**
3. 确认顶部显示 `Spark`，或在无 Key 时显示 `Mock`

### 第 6 步：开始演示

进入会话中心，直接提问：

```text
我不懂函数极限，讲清定义、常见误区，并给一个例题。
```

系统会自动生成思维导图、练习题、讲义、学习路径和 Markdown 教学版 PPT。

### 第 7 步（可选）：下载资源

在资源中心点击下载，当前主链路输出稳定可打开的 Markdown 文件。

## 常见问题

### Q: 我没有 API Key 怎么办？
A: 可以直接用 Mock fallback 演示完整学习闭环；需要真实模型时再填写 Spark 或 DeepSeek Key。

### Q: deepseek-v4-pro 连接失败？
A: 可能是账户权限不足。可以尝试改用以下模型：
- `deepseek-v4-flash`（更快更便宜）
- `deepseek-chat`（旧版兼容）

在设置页的模型下拉框中选择切换即可。

### Q: GitHub 上为什么没有 API Key？
A: 这是**正常的**。API Key 保存在本机 `backend/.env` 文件中，该文件已加入 `.gitignore`，不会被提交到 GitHub。每个人需要自己填写。

### Q: API Key 保存在哪里？
A: 保存在项目目录下的 `backend/.env` 文件。前端页面的 API Key 输入框类型为 `password`，不会明文展示。后端日志也不会打印 API Key。

## 安全说明

- API Key 仅保存在本机 `backend/.env`
- `backend/.env` 不会提交到 GitHub（已加入 `.gitignore`）
- 页面不展示完整 Key（password 输入框）
- 后端日志不打印 Key
- 前端不存储 Key 到 localStorage
