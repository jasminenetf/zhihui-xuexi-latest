# 科大讯飞能力使用说明

**适用于:** 比赛答辩 / PPT 附件 / 评委查阅
**版本:** 比赛版 v3 (方案 A+)
**日期:** 2026-05-24

---

## 概述

本项目（智能学习助手）已接入科大讯飞 AI 能力，并以国产模型可配置、多模态可扩展的方式展示。以下说明系统已实现的能力、配置方法及未来扩展方向。

---

## 1. 已实现：星火大模型接入

### 接入方式

本项目通过科大讯飞星火大模型 HTTP 接口实现接入，完全兼容 OpenAI SDK：

```
Base URL: https://spark-api-open.xf-yun.com/x2
鉴权字段: APIPassword
模型:     spark-x
```

### 配置方法

在 `.env` 文件中配置以下参数即可切换至星火模型：

```env
LLM_PROVIDER=spark
LLM_PROVIDER=spark
SPARK_BASE_URL=https://spark-api-open.xf-yun.com/x2
SPARK_API_PASSWORD=<您的APIPassword>
SPARK_MODEL=spark-x
```

或通过前端"系统设置"页面，选择"星火 Spark"并填入 APIPassword 后保存。

### 当前推荐配置

比赛演示推荐使用 Spark X2：

- Base URL: `https://spark-api-open.xf-yun.com/x2`
- Model: `spark-x`
- APIPassword: 用户自己的科大讯飞 APIPassword

没有 API 时，系统仍可使用本地演示模式完成学习闭环。

---

## 2. 模型层三层 Fallback

系统设计了完善的三层容灾机制：

```
第一层: Spark X2          ← 国产模型，优先尝试
第二层: 备用模型/兼容实现  ← 保证开发调试可用
第三层: 本地演示模式       ← 离线容灾，确保学习闭环可演示
```

当某一层不可用（密钥缺失、网络超时、服务异常）时，系统自动降级到下一层，
并在响应中记录 fallback 来源和原因，确保学习流程不中断。

## 4. 微课讲解稿（可选轻量展示）

系统可选支持"生成微课讲解稿"功能：

- **输入**: 当前 AI 回答 + 引用来源 + 学习路径
- **输出**: 60 秒课堂讲解稿文本
- **展示**: "数字人课堂助手"卡片内
- **依赖**: 无外部 API，纯文本生成
- **后续**: 可接入 TTS 将讲解稿转为语音，或接入数字人进行口播

> 注意：当前版本**不**调用科大讯飞 TTS 或数字人视频 API，
> 讲解稿为纯文本输出。语音合成和数字人属于明确的下一步扩展方向。

## 5. 答辩推荐表述

### 针对评委可能的提问

**Q: 你们是否使用了国产大模型？**

A: 是的。本系统已经实现科大讯飞 Spark X2 接入，推荐配置为
Base URL `https://spark-api-open.xf-yun.com/x2`、Model `spark-x`，
通过用户自己的 APIPassword 完成鉴权。没有 API 时可进入本地演示模式。

**Q: 你们有多模态或数字人能力吗？**

A: 我们采用轻量化策略。当前版本优先保证学习闭环稳定性，
已完成课程知识库、学生画像、多智能体协同、引用溯源、多资源生成、学习效果评估，
并提供函数极限、导数定义、定积分三个主题的轻量 HTML/SVG/CSS 动画预览。
当前不生成 mp4，后续可继续扩展为视频或数字人讲解。

**Q: 讯飞能力在你们项目中的定位是什么？**

A: 分三层。第一层已交付：星火大模型可配置接入，国产模型支撑。
第二层当前可选：微课讲解稿，为语音/数字人提供前置内容。
第三层未来扩展：语音合成、OCR、完整数字人助手。
我们不夸大当前实现，也不回避技术储备。

---

## 6. 重要说明

1. **不夸大**: 当前推荐使用 Spark X2 真实生成；如果网络或 APIPassword 配置异常，
   系统会明确进入本地演示模式，不把 fallback 伪装成真实模型输出。

2. **不泄露密钥**: 所有 API Key、APIPassword、JWT Secret
   均不包含在代码仓库中，仅在 `.env` 文件中本地配置。

3. **演示优先**: 当前比赛版以学习闭环稳定性为首要目标，
   因此默认使用已验证的 DeepSeek 模型。

4. **技术诚实**: 发行包不包含真实 APIPassword。评委或演示者需要使用自己的
   科大讯飞 APIPassword 配置 Spark X2。
