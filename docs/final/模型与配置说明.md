# 模型与配置说明

## 支持的大模型

### 讯飞星火 Spark X2（比赛推荐）

| 模型 | 说明 | 推荐程度 |
|------|------|----------|
| `spark-x` | 科大讯飞 Spark X2 OpenAI 兼容模型 | ⭐⭐⭐ 推荐 |

- **Base URL**: `https://spark-api-open.xf-yun.com/x2`
- **认证字段**: APIPassword
- **配置方式**: 在前端“模型与设置”中填写用户自己的科大讯飞 APIPassword
- **超时**: 建议 120-180 秒，真实生成可能需要等待

### DeepSeek / 本地演示模式（备用）

| 模型 | 说明 |
|------|------|
| `deepseek-chat` | DeepSeek 兼容备用模型 |
| `mock` | 本地演示模板，保证无 API 时仍可完成学习闭环 |

系统保留 fallback 能力：Spark 真实生成失败时，可切换到备用模型或本地演示模式。

## 配置文件

### `backend/.env`

项目配置由 `backend/.env` 文件管理。该文件：
- **不在 GitHub 上**（已加入 `.gitignore`）
- 每个人需要自己创建（可复制 `.env.example`）
- API Key 通过前端设置页填写并自动保存到此文件

### `backend/.env.example`

模板文件，包含所有可配置项及其默认值。提交到 GitHub 供参考。

### 关键配置项

```bash
# 模型选择：spark 或 mock
LLM_PROVIDER=spark

# Spark X2 配置
SPARK_BASE_URL=https://spark-api-open.xf-yun.com/x2
SPARK_MODEL=spark-x
SPARK_API_PASSWORD=          # 用户自己的科大讯飞 APIPassword
LLM_TIMEOUT_SECONDS=180
```

## Fallback 机制

当主模型调用失败时，系统会自动尝试备用模型：

- **Spark 为主** → 若网络或 APIPassword 配置异常，进入备用模型或本地演示模式
- **无 API** → 使用本地演示模式，仍可展示对话、资源生成、练习、错题、报告和路径闭环

## 安全机制

1. **API Key 隔离**: 仅保存在 `backend/.env`，不进入版本控制
2. **前端保护**: API Key 输入框为 `password` 类型，不显示明文
3. **日志脱敏**: 后端日志只打印 `key=sk-4***xxxx` 格式的掩码
4. **API 响应脱敏**: `/api/settings/status` 只返回 `configured: true/false`，不返回 Key
5. **localStorage 隔离**: API Key 不写入浏览器 localStorage

## 配置方式

### 方式一：前端设置页（推荐）

打开系统设置页面，在 Spark 配置区域填写：

- Base URL: `https://spark-api-open.xf-yun.com/x2`
- Model: `spark-x`
- APIPassword: 用户自己的科大讯飞 APIPassword

适合非开发者。

### 方式二：直接编辑 .env

```bash
cp backend/.env.example backend/.env
# 编辑 backend/.env 填写 API Key
```

然后重启后端。适合开发者。
